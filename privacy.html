개인정보처리방침

Assessment Plan(교수학습평가계획서 웹 입력 도구, 이하 "앱")은 교사가 평가계획서를 작성·저장·인쇄할 수 있도록 돕는 정적 웹 페이지입니다. 앱 운영자는 사용자의 입력 내용을 수집하거나 보관하는 서버를 운영하지 않습니다.

1. 저장되는 정보

  • 이 기기의 브라우저: 작성한 문서 내용은 사용자의 브라우저(localStorage)에만 저장됩니다.
  • 사용자의 Google 드라이브(선택): 사용자가 "Google 계정 연결"을 선택한 경우에 한해, 문서가 사용자 본인의 Google 드라이브 교수학습평가계획서 폴더에 JSON 파일로 저장됩니다.

2. 요청하는 Google 권한

앱은 https://www.googleapis.com/auth/drive.file 권한만 요청합니다. 이 권한으로는 앱이 만든 파일만 읽고 쓸 수 있으며, 사용자의 다른 드라이브 파일, 이메일, 연락처 등에는 접근하지 않습니다. 로그인 토큰은 브라우저 메모리에만 존재하며 별도로 저장하거나 외부로 전송하지 않습니다.

3. 제3자 제공 및 수집

앱 운영자는 사용자 데이터를 수집·분석·판매하거나 제3자에게 제공하지 않습니다. 광고와 추적 도구를 사용하지 않습니다.

4. 삭제

브라우저 데이터를 지우면 이 기기의 문서가 삭제되고, Google 드라이브의 파일은 사용자가 드라이브에서 직접 삭제할 수 있습니다. Google 계정 설정의 "서드파티 앱 및 서비스 연결"에서 앱의 접근 권한을 언제든 철회할 수 있습니다.
