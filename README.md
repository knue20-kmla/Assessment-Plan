# Assessment Plan (교수학습평가계획서)

2026학년도 1학기 교수학습평가계획서 양식을 웹에서 입력·계산·미리보기·인쇄할 수 있게 만든 단일 HTML 앱입니다.

- `index.html` 하나로 동작합니다(서버 불필요). 입력 내용은 브라우저(localStorage)에만 저장됩니다.
- 시수 누계, 영역별 반영비율, 논·서술형 합계, 수행평가 100점 유지, 배점 합계 자동 계산
- `■` 줄 자동 추가, 시기 블록·수행평가 영역·문구 항목 추가/삭제, 제목 수정
- 편집/미리보기 전환, 인쇄(PDF 저장) 및 쪽 구분선 표시
